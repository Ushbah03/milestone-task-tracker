# 🚀 Milestone Task Tracker

A modern React-based **Milestone/Task Tracker** designed to help users organize and manage their daily tasks efficiently. The application provides an intuitive interface for creating, tracking, and managing tasks with priority levels, due dates, search, filtering, and progress tracking.

This project was developed as part of a **Frontend AI Internship Assignment**, using AI as a development assistant while manually reviewing, testing, and refining the final implementation.

---

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 📝 Edit tasks with inline editing
- 🗑️ Delete tasks
- 🎯 Assign priority levels (High, Medium, Low)
- 📅 Set due dates
- 🔍 Search tasks
- 📂 Filter tasks (All, Active, Completed)
- ↕️ Sort tasks by:
  - Priority
  - Due Date
  - Newest
- 📊 Progress tracking
- 📈 Priority statistics
- 🔔 Toast notifications
- 🎨 Professional dark-themed user interface
- ♿ Keyboard accessibility support
- 📱 Responsive layout

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/milestone-task-tracker.git
```

### 2. Navigate to the project

```bash
cd milestone-task-tracker
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

---

## 🎯 How to Use

1. Enter a task description.
2. Select a priority level.
3. Optionally choose a due date.
4. Click **Add Task**.
5. Click the task node to mark it complete.
6. Double-click a task to edit it.
7. Use the search, filter, and sort options to organize tasks.
8. Delete tasks when they are no longer needed.
